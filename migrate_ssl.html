Vue + Flask + Nginx HTTPS 遷移指南

本文件說明如何將運行於 16.146.141.237 的 Vue2 前端與 Flask 後端，透過 Nginx 反向代理配置為 HTTPS 環境。

注意： 本教學使用 OpenSSL 自簽憑證。由於是針對 IP 位置而非網域簽署，瀏覽器會顯示「不安全」的警告，這是正常現象，點擊「進階 -> 繼續前往」即可。

第一步：生成 SSL 自簽憑證

在伺服器上建立存放憑證的目錄，並生成效期一年的憑證。

# 1. 建立目錄
sudo mkdir -p /etc/nginx/ssl

# 2. 生成私鑰與憑證
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
    -keyout /etc/nginx/ssl/nginx.key \
    -out /etc/nginx/ssl/nginx.crt

執行後系統會詢問資訊，請在 Common Name 欄位填入您的 IP：16.146.141.237，其餘欄位可選填。

第二步：配置 Nginx

修改 Nginx 設定檔（通常位於 /etc/nginx/sites-available/default），設定強制 HTTPS 跳轉與反向代理。

# 1. HTTP -> HTTPS 強制轉址
server {
    listen 80;
    server_name 16.146.141.237;

    return 301 https://$host$request_uri;
}

# 2. HTTPS 主配置
server {
    listen 443 ssl;
    server_name 16.146.141.237;

    # SSL 憑證路徑
    ssl_certificate /etc/nginx/ssl/nginx.crt;
    ssl_certificate_key /etc/nginx/ssl/nginx.key;

    # SSL 安全性優化
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # --- 前端 (Vue) ---
    location / {
        # 請確認這是您 npm run build 後的 dist 路徑
        root /var/www/html/dist; 
        index index.html;
        
        # 解決 Vue Router History Mode 重新整理 404 問題
        try_files $uri $uri/ /index.html;
    }

    # --- 後端 (Flask API) ---
    # 將 /api 開頭的請求轉發給 Flask (Port 5000)
    location /api/ {
        proxy_pass http://127.0.0.1:5000/; 
        
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

設定完成後，請測試並重新載入 Nginx：

sudo nginx -t && sudo systemctl reload nginx

第三步：修改 Vue 前端代碼

這是最關鍵的一步。由於網頁已變為 HTTPS，不能再直接呼叫 HTTP 的 5000 port，必須改用相對路徑透過 Nginx 轉發。

請找到您設定 axios 或 API 請求的地方：

// ❌ 錯誤寫法 (原本的寫法)
// axios.defaults.baseURL = 'http://16.146.141.237:5000';

// ✅ 正確寫法 (改為相對路徑)
// Nginx 會自動將 /api 對應到後端的 :5000
axios.defaults.baseURL = '/api';

修改完畢後，請務必重新打包專案：

npm run build

第四步：防火牆設定

確保伺服器允許外部存取 443 埠口。

sudo ufw allow 443

如果是雲端主機 (如 AWS/GCP)，請記得在安全群組 (Security Group) 新增 Inbound Rule 允許 HTTPS。
